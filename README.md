# NE1 Samsung Finance+ Calculator

เว็บไซต์คำนวณเงินดาวน์ ดอกเบี้ย และค่างวด โดยล็อกดอกเบี้ยที่ 0.87% ต่อเดือน

## Deploy ด้วย GitHub Pages
1. แตกไฟล์ ZIP นี้
2. อัปโหลด `index.html` และ `README.md` ไว้ที่ root ของ GitHub repository
3. ไปที่ **Settings → Pages**
4. เลือก **Deploy from a branch**, branch `main`, folder `/ (root)` แล้วกด Save
5. เปิด URL ที่ GitHub Pages แสดงเมื่อ deploy เสร็จ

## สูตรคำนวณประมาณการ
- เงินดาวน์ = ราคาเต็ม × เปอร์เซ็นต์เงินดาวน์
- ยอดจัด = ราคาเต็ม − ส่วนลด − เงินดาวน์
- ดอกเบี้ยทั้งหมด = ยอดจัด × 0.87% × จำนวนเดือน
- ค่างวดต่อเดือน = (ยอดจัด + ดอกเบี้ยทั้งหมด) ÷ จำนวนเดือน

หมายเหตุ: เป็นการคำนวณประมาณการแบบ Flat Rate ไม่ใช่การยืนยันยอดอนุมัติจริงของ Samsung Finance+ กรุณาตรวจสอบเงื่อนไขในระบบก่อนเสนอขาย
